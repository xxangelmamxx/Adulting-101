The following **additional** features are implemented:

- [X] Each task card opens its own detail page with step-by-step instructions pulled from the database by id
- [X] Users can filter tasks by category (Money, Paperwork, Home, Health, Kitchen, Car, Career) and by difficulty (Easy, Medium, Hard), on top of the search bar
- [X] Steps can be checked off as you complete them, with a progress bar that is saved in the browser so progress stays after a refresh
- [X] Steps have to be completed in order: later steps stay locked until the one before is checked, so no skipping ahead
- [X] Confetti celebration when every step of a task is finished
- [X] "Your adulting level" tracker on the home page that levels up as you complete tasks (Baby Adult → Certified Grown-Up)
- [X] Task cards show a progress percentage or a "Done" badge for tasks you have started or finished
- [X] Previous / next links on each task page to move between tasks
- [X] Pressing "/" anywhere on the home page jumps to the search bar
- [X] Custom 404 page for unknown routes and task ids that do not exist
- [X] Custom neo-brutalist theme built on Pico CSS, with light and dark mode and a responsive layout for phones
